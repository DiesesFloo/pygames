# Ziel
Alle können ein (ziemlich) einfaches Spiel basierend auf pygame (konkret: pygame-ce) programmieren. Als Beispiel nehmen wir single player pong.
In dieser Session nutzen wir noch keine KI, setzen aber am Ende alles dafür auf --> Alle Studierenden haben copilot mit einem lokalen Modell lauffähig eingerichtet.

Los geht's mit der Installation von pygame-ce:

git clone https://github.com/TillHaenisch2/pygames

python -m venv pygames
cd pygames
. bin/activate
pip install pygame-ce

cd session1
python game.py
